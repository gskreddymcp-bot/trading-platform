# Big Picture

Market Intelligence OS V1 is a decision-support platform for Indian markets.

It scans:
- Indian index structure
- top stock breadth
- option-chain support/resistance
- global context
- news risk
- setup candidates
- journal outcomes

V1 does not execute trades.

The permanent asset is not a strategy. The permanent asset is the process:
data -> structure -> option-chain confirmation -> setup -> risk filter -> journal.
